# Script template

Write the headings and labels in the script's language (use the language file's labels). Delete what doesn't apply.

```
# <Title>

<Platform> · <format> · ~<duration> · <language-variant>

## HOOK (0:00–0:03)
[<intent label>: one verb]
[<visual label>: what the viewer sees in the first frame]
[<text label>: on-screen text]
<Spoken line, with full punctuation.>

## <BEAT NAME> (0:03–0:15)
[<intent label>: one verb, changes when the beat changes]
<Spoken lines. One idea per sentence. Commas where the speaker breathes, a period where each idea ends.>
[<visual label>: ...]

## <BEAT NAME> (...)
...

## CTA (...)
<One action.>

---
Notes
- Duration (measured with script_stats.py): <m:ss> (<N> spoken words at <rate> wpm)
- Variant: <variant and why>
- Voice: <calibrated with profile X / not calibrated>
- Assumptions: <list, or none>
- Placeholders: <list, or none>
- Sources: <list, or "no factual claims">
- Unverified: <list, or none>
- Alternative hook: <mechanism> · <line>
- Alternative CTA: <line>
- Before recording: read it aloud twice, mark where you stumble, and tell me which lines to fix.
```

For short-form, timestamps per beat. For long-form, timestamps per section and a re-hook line flagged in each section.
